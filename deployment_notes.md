# Deployment Plan

## Frontend
Streamlit web app with search bar and movie grid

## Backend
Pickle files: movies.pkl, similarity.pkl loaded at startup

## Hosting
Selected: Streamlit Cloud (free, GitHub integration)

## Steps
1. Push code to GitHub
2. Connect repo to Streamlit Cloud
3. Set TMDB_API_KEY as secret in Streamlit Cloud settings
4. Deploy!
